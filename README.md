# Village-Defender

> **⚠️️ Status:** Work in Progress (WIP). More features and updates will be added soon!

A simple 2D game made with Pygame module in Python with AI assistance. The main character - "Steve" defends the Village from Hunters who loot the village and kill all their animals.

**About Game**
Steve - Main Character , Protects the the village from the Hunters who live in the forest and usually come to loot the village, take all their food and kill their animals . Steve is the bravest and the strongest of them and decides to devote his life to protect the village till his last breath.

## Built With
* **Language:** Python
* **Library:** Pygame
* **AI Assistant:** Built with the help of **Gemini Flash-Lite** to write and structure the code.
